# AI Personas — Design Proposal Package

Start with **AI-PERSONAS-DESIGN-PROPOSAL.md**.

The proposal contains the full design, 30 main sections, seven Mermaid diagrams, and five illustrated posters reused from the conversation. It is a conceptual and behavioral proposal, not application code or a repository patch plan.

## Package layout

| Item | Purpose |
|---|---|
| AI-PERSONAS-DESIGN-PROPOSAL.md | The complete proposal and acceptance requirements |
| assets/ | Five poster images referenced by relative links |
| sources/ | Byte-for-byte copies of all five supplied Markdown reports, plus a source manifest |
| package-validation.json | Structural and packaging checks, explicitly separate from product acceptance tests |

Keep the proposal, assets folder, and sources folder together so local image and source links resolve. A Mermaid-capable Markdown viewer can render the editable diagrams. Each diagram also has a prose reading, and the written requirements contain the substantive design without relying on the images.

The original source reports include historical code-level recommendations and prior artifact links. They are retained for provenance; they are not part of the code-free conceptual requirements, and their historical links and current repository claims have not been revalidated.

## Evidence status

The proposal clearly separates source-derived requirements from new extensions for embodiment, society governance, sensitive human-facing uses, ongoing services, physical interfaces, worksheets, and open-source governance. The later v1.2 source governs conceptual conflicts with earlier reports.

The 26 mechanical, 12 behavioral, and six extension acceptance tests are specifications, not executed results. No live persona campaign, current repository audit, engineering simulation, physical test, or deployment assurance assessment was performed for this delivery. Markdown structure, local links, image readability at the file level, source-copy integrity, and package integrity were checked. Mermaid browser rendering was not independently verified.
