Earlier S1–S5 briefs, the selector vendor-source page, and superseded design addenda now live in Git history. Their useful authority, resource, privacy, evidence, and cooperation requirements are consolidated into the current normative documents. Their old architecture choices are historical, not selectable alternatives in active navigation. Old paths are discoverable from the manifest and complete pinned tree.

The 8 October revision requires semantic OCEAN coverage and distinct VAD modeled affect without requiring numeric scales or stereotyped action mappings. Every authored reusable fragment embodies the persona's own perspective, and every persona-level LLM invocation receives a maintenance request and has an explicit outcome. The meaning, call coverage, and failure rules live in the normative chapters. The source pages explain the motivation and preserve the earlier, weaker obligations for honest comparison.

The adopted target is not an assertion that the implementation has caught up. Human psychometrics supplies vocabulary; LLM studies support bounded component claims; the complete integration remains untested here. Neither citations nor structured-output compliance provide a 100% guarantee of useful character, truthful learning, or reliable effects. New empirical claims need accessible primary sources, exact versions or dates, the precise supported claim, and limitations. New runtime claims additionally need exact implementation revisions, observations, and the applicable evaluation criteria.
