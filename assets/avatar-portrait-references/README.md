# Characteristic-grounded portrait references

These four images are optional visual references, not a substrate portrait
contract. Person-like appearance, characteristic grounding, and any other
presentation requirement apply only when exact authenticated principal/user
intent asks for them. They are **portrait candidates, not admitted identity
assets**. A candidate may become a public avatar only after the exact persona
authors a signed declaration binding explicit MIME, content hash, length,
identity role, and byte provenance. UI code must never use these files as an
unsigned override or gate an otherwise active persona when no portrait exists.

The historical identity records used for this reference pass contained
qualitative persona-authored characteristics. Those characteristics informed
these optional examples only; the kernel neither requires nor interprets them.

## Example task-specific art direction

These constraints are illustrative art direction for the exact reference pass,
not runtime prompts, identity admission rules, or universal UI requirements.

- square, centered head-and-shoulders portrait readable at 104 px;
- unmistakably a person, in a persona-selected artistic style;
- stable work posture expressed through face, posture, composition, texture,
  and palette;
- task or role motifs only as faint secondary background context;
- no text, logo, initials, robot, mask, document icon, or CAD object replacing
  or obscuring the person; and
- no inference of protected physical attributes from psychological traits.
